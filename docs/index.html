Wardex

Auditable security and compliance decisions. Risk-based release governance for NIS2 · DORA · CRA · EU AI Act.

GitHub Changelog CRA Article 14
Install Quickstart

What it does

  • Correlates scanner output against the CISA KEV catalogue to identify actively exploited CVEs
  • Generates signed CRA Article 14 notification artifacts with HMAC-SHA256 audit chain
  • Evaluates release risk per asset context — the same CVE can ALLOW, WARN, or BLOCK depending on criticality, exposure, and compensating controls
  • Cross-references documented vs implemented controls against ISO 27001, NIS2, DORA, and CRA Article 14 catalogues
  • Returns distinct exit codes for each outcome: freshness advisory (6), gate block (10), compliance gap (11), active exploitation (12), and duplicate release (13)
  • Configuration Provenance Link (CPL) — cryptographically binds gate decisions to the exact config in force, with hash-chain audit verification

Supported frameworks

ISO/IEC 27001:2022

Annex A control mapping with maturity scoring and evidence classification.

NIS 2

Cyber hygiene, supply chain, and incident reporting controls for essential entities.

DORA

ICT risk management, digital operational resilience, and third-party oversight.

CRA Article 14

Active exploitation notification, KEV correlation, and HMAC-SHA256 signed audit trail for EU Cyber Resilience Act.

Quickstart

# Install
go install github.com/had-nu/wardex/v2@latest

# Convert scanner output to Wardex format
wardex convert grype test/usability/grype-results.json > vulns.yaml

# Evaluate with asset context
wardex evaluate \
  --evidence vulns.yaml \
  --config doc/examples/wardex-config.yaml

Exit codes: 0 OK · 1 generic error · 3 integrity · 4 store inconsistent · 5 expiring soon · 6 freshness advisory · 10 BLOCK · 11 compliance failure · 12 active exploitation · 13 duplicate release

Install

Requires Go ≥ 1.27. Current release: v2.6.0.

go install github.com/had-nu/wardex/v2@v2.6.0

Or build from source:

git clone https://github.com/had-nu/wardex.git
cd wardex && make build
