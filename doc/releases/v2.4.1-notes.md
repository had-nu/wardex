# Wardex v2.4.1 Release Notes

**Release Date:** 2026-07-17
**Version:** 2.4.1
**Theme:** Code Health Audit Wrap-Up

---

## Highlights

### Typed Decision Model
Introduced `model.Decision` with `DecisionAllow`, `DecisionBlock`,
`DecisionWarn` constants, replacing all raw `"allow"`/`"block"`/`"warn"`
string comparisons across `pkg/releasegate`, `pkg/statestore`, `pkg/report`,
`cmd/evaluate`, `cmd/art14`, `cmd/aggregate`, `pkg/accept`, and `main.go`.

**Impact:** decisions are type-checked at compile time — no more stringly-typed
gate logic.

### Tool Relocation
`cmd/gen-sbom/` moved to `tools/gen-sbom/`, separating build-time tooling from
the CLI command tree.

### RBAC Extraction
Duplicated RBAC/profile logic extracted into `config.ApplyProfile`; shared by
`main.go` and `evaluate_helpers.go`.

### Heuristic Scoring Formula Removed from Docs
The heuristic scoring formula was documentation-only and never consumed by the
scorer — removed from README (PT) and README-en (EN) to stop misleading
users.
