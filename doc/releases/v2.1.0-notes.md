# Wardex v2.1.0 Release Notes

**Release Date:** 2026-06-19
**Version:** 2.1.0
**Theme:** Distribution & Reporting — Docker, Action, HTML

---

## Highlights

### Docker CI + Hardened Image
Reproducible multi-stage Dockerfile (`Dockerfile`) with distroless nonroot
base. `docker.yml` CI workflow builds, tests, and signs images with cosign
keyless.

**Impact:** containerized gate runs with a rootless, signed image.

### GitHub Action
Reusable composite action (`action.yml`) for CI/CD gate checks. Inputs:
`config-path`, `gate-log`, `kev`, `strict`, `dry-run`, `out-file`.

**Impact:** `wardex evaluate` runs inside GitHub Actions in one `uses:` line.

### HTML Report
`wardex evaluate --out-file report.html` emits a self-contained HTML report
with inline SVG charts (`pkg/report/html.go`).

**Impact:** boardroom-ready reports without external chart tooling.

### Native SBOM + Cosign
`cmd/gen-sbom/main.go` produces CycloneDX-compatible SBOMs natively. Release
artifacts signed keyless with cosign.
