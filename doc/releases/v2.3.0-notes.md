# Wardex v2.3.0 Release Notes

**Release Date:** 2026-07-17
**Version:** 2.3.0
**Theme:** Deterministic Canonicalization & 3CP Tool Attestation

---

## Highlights

### CBOR Deterministic Encoding
CPL canonicalization now uses CBOR Core Deterministic Encoding (RFC 8949 §4.2.3)
via `github.com/fxamacker/cbor/v2` instead of `encoding/json`.

**Impact:** byte-identical serialization across implementations for the same
semantic data — closes the float/int, unicode-normalization, and map-key-order
edge cases JSON left open.

### WexState v2
`SealMessage()` produces CBOR deterministic bytes instead of `\n`-separated
text; timestamps use CBOR RFC3339. The `.wexstate` file stays YAML for
readability — only the signed message changes. `IsVersion2()` and
`SealMessageV1()` preserve legacy verification.

**Impact:** deterministic sealed configs; safe v1→v2 fallback in
`VerifySeal`.

### 3CP Tool Attestation
New `pkg/attest` defines 3CP provenance envelopes (`ToolAttestation`,
`SignedAttestation`) with CBOR deterministic signing and Ed25519 signatures;
formalized in `spec/cddl/tool-attestation.cddl`. The `Anchorer` interface is
purely 3CP-agnostic — Gleipnir is one backend among equals (embedded, grpc,
noop).

**Impact:** `converted_by` provenance upgrades from a best-effort string to a
cryptographically verified envelope.

### Formal CDDL Schemas
`spec/cddl/` now carries `cpl-entry.cddl`, `wexstate.cddl`, and
`tool-attestation.cddl` — design artifacts and the foundation for conformance
testing.

## Detailed Changes

### Package/API Changes
- **BREAKING**: `SealMessage()` now returns `([]byte, error)` instead of
  `[]byte`. Callers updated: `SealConfig()`, `VerifySeal()`.
- **BREAKING**: CPL `config_hash` values changed (CBOR replaces JSON). Existing
  audit logs must be re-hashed with the new canonicalizer; legacy logs fail
  link verification if re-hashed.
- `pkg/attest/attestation.go` (new) — 3CP tool provenance.
- `pkg/provenance/anchorer.go`, `pkg/provenance/factory.go` — agnostic
  `Anchorer` abstraction.
- `pkg/trust/wexstate.go`, `pkg/trust/wexstate_cbor.go` — WexState v2 + v1
  fallback.
- `go.mod`: `github.com/fxamacker/cbor/v2 v2.9.0` promoted to direct.

### Security
- Deterministic canonicalization hardening (referenced above).
- 3CP attestation provides cryptographic non-repudiation for converted
  evidence.

## Compatibility & Migration

- **Migration required**: re-hash CPL configs and refresh fixtures for the CBOR

  instructions, including test-fixture verification and CI pipeline updates.
- v1 `.wexstate` files still verify via the lenient fallback path.
