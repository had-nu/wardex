# Wardex v2.1.1 Release Notes

**Release Date:** 2026-06-20
**Version:** 2.1.1
**Theme:** CI & Distribution Fixes

---

## Highlights

### Module Path /v2 Fix
Added the missing `v2` module path suffix so `github.com/had-nu/wardex/v2`
resolves correctly through the Go proxy.

**Impact:** `go install` and Go proxy consumers no longer fail on the v2
module path.

---

## Detailed Changes

### Fixed
- **Cosign sign-blob**: added `--output-signature` and
  `--output-certificate` flags so signatures and certificates are emitted for
  release verification.
- **Docker workflow SHA pins**: replaced placeholder test mocks with real
  cosign/goreleaser SHAs.
- **GoReleaser failures**: CI release workflow fixes for the `/v2` module
  path.
- **gosec G703**: wrapcheck lint fix in `pkg/accept`.
- **Windows build**: `log/syslog` guarded behind `!windows` build tag.
- **CI badges**: removed the always-failing CI badge; NIST CSF listing
  reflected.
- **Doc audit**: version bumps, dead links, `dev` → `main` branch references,
  missing badges.
