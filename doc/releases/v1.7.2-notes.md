# Wardex v1.7.2 Release Notes

**Release Date:** 2026-04-21
**Version:** 1.7.2
**Theme:** SDK, Calibration & Policy Management

---

## Highlights

### Programmatic SDK
New `pkg/sdk` exposes `Analyze()` programmatically so external tooling can run
compliance assessment without shelling out to the CLI. Example in
`examples/sdk/` includes a `controls.yaml` fixture.

**Impact:** Wardex becomes embeddable — CI systems can integrate the gate
engine directly.

### Calibrated Risk Gate (NAICS Profiles)
Risk calibration now uses statistical bootstrapping and organizational profiles
synchronized with NAICS sectors (`data/calibration.json`). The calibration
enhancement was validated by a high-fidelity convergent validity study.

**Impact:** context-weighted scoring reflects real sector risk, not generic
thresholds.

### Policy Management
New `internal/policy` package with schema and loader, plus a `wardex policy`
subcommand (`validate | list | add`). ISO 27001 technological controls shipped
as `frameworks/iso27001/technological_controls.yml`; SOC 2, NIS 2, and DORA
templates added via `frameworks/`.

**Impact:** operators can now validate and manage control frameworks directly
from the CLI.

## Detailed Changes

### Added
- **SDK API** (`pkg/sdk/assess.go`: `Analyze`, `AnalyzeWithConfig`,
  `LoadControls`, `LoadFramework`, `Report`, `SnapshotSave/Load/Diff`) with
  `examples/sdk/main.go` and `examples/sdk/controls.yaml`.
- **NIS2/DORA/SOC2 templates**: `frameworks/nis2/cyber_hygiene.yml`,
  `frameworks/dora/resilience_controls.yml`, `frameworks/soc2/trust_services.yml`.
- **Calibrated Risk Gate**: `data/calibration.json`; statistical bootstrapping in
  calibration; NAICS organizational profile synchronization.
- **Playbook**: `WARDEX_PLAYBOOK.md` and `doc/USECASES.md` (10 didactic
  scenarios).
- **Imported raw CBOR fixtures**: `data/dataset_2025-03-01.json`.

### Changed
- **Convergent validity study (v3)**: high-fidelity validation of the risk
  model.
- **Documentation/CLI banner redesign**; `doc/TECHNICAL_VIEW.md` refreshed.
- **Dependencies**: AWS SDK v2 and Cloud Logging bumped; GitHub Actions updated
  to latest versions.

### Fixed
- `.golangci.yml` migrated to v3 format.
- StaticCheck `QF1003` resolved (if/else → switch).
- `git clone` URL corrected in CONTRIBUTING and RELEASES; `make build`
  standardized.
- `LoadMany` same-ID/layer deduplication and `Asset` schema consistency fixes.

### Security
- Empirical research scripts isolated to `/research`.
- Internal docs moved to `/internal/doc/` for a cleaner public clone.
