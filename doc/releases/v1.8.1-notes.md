# Wardex v1.8.1 Release Notes

**Release Date:** 2026-05-07
**Version:** 1.8.1
**Theme:** Build Fix

## Highlights

### Go-Embed Path Fix
`test/embed.go`'s `go:embed` directive pointed at a path that did not track
`wardex-risk-simulator.jsx`, breaking builds that embed the interactive risk
simulator.

**Impact:** embedding now resolves the simulator asset reliably; builds no
longer fail on the embed directive.

---

## Detailed Changes

### Fixed
- **Build issue**: fixed `go:embed` path for `wardex-risk-simulator.jsx` in
  `test/embed.go` so the asset is tracked and embedded.
