# Wardex v2.5.0 Release Notes

**Release Date:** 2026-08-20
**Version:** 2.5.0
**Theme:** Go 1.27 & Architectural Hardening

---

## Highlights

### Go 1.27 Migration
`go.mod` declares `go 1.27.0`; `GOTOOLCHAIN=auto`; Docker builds on
`golang:1.27-alpine`. `go fix` modernizations applied (`omitzero`), a duplicated
`Timestamp` field fixed in `cmd/chain/seal.go`, and a CI gate fails on any
`go fix` diff. CI runs build/test (`-race` + coverage threshold), vet
(including `stdversion`), golangci-lint v2.13.1, govulncheck, and gosec on
Go 1.27.0.

**Impact:** modern toolchain, standards-version safety, and zero-drift codegen
enforced in CI.

### Orchestrator Extraction
New `pkg/orchestrator` owns the full evaluation pipeline.
`EvaluationPipeline.Run` and `RunGate` never call `os.Exit` and never write
directly to `os.Stderr` — they log through an injected `*slog.Logger` and
return the exit code for the caller to apply. `main.go::runWardex` (28 lines)
and `cmd/evaluate::runEvaluate` (26 lines) are now thin wrappers.

**Impact:** Wardex becomes embeddable and testable as a library; the CLI is a
facade.

### Centralized File I/O
`pkg/cli/safefile.go` (`SafeReadFile`/`SafeWriteFile`) concentrates all path
validation and `#nosec G304` annotations; 46 call sites migrated. Zero
`os.ReadFile` remains outside `safefile.go`.

### Structured Logging & Context
- New `pkg/ui/logger.go` (`NewLogger`, `NewLoggerTo`, text/JSON handlers,
  `[PREFIX]` TTY style, syslog endpoint). All `pkg/*`
  `fmt.Fprintf(os.Stderr, ...)` sites replaced.
- `context.Context` threaded through `pkg/epss`, `pkg/trust`,
  `internal/notification`, `pkg/accept` forwarders/notifiers, `pkg/gate`, and
  `cmd/evaluate` helpers to the final network call.

### Acceptance Decomposition
`pkg/accept` split into `store/`, `verify/`, `audit/`, `forward/`, `rules/`
sub-packages with no import cycles. `pkg/accept` is now a **deprecated
re-export facade (removed in v3.0)**. `ConfigHash` moved to
`internal/cpl/hash.go`; `ReadReport` moved to `pkg/report/reader.go`.

## Detailed Changes

### Tests & Fuzzing
- `pkg/orchestrator` coverage ≥ 80% (currently 83.5%): evaluation pipeline,
  gate pipeline (sealed `.wexstate` configs, state store + trend, Art14
  active-exploitation, strict/dry-run/json/csv), helpers.
- Property-based fuzz tests with invariants:
  - `pkg/ingestion`: controls must have non-empty ID/Name, maturity `1..5`,
    known layer, positive context weight — caught and fixed an unvalidated
    layer coercion bug (`layer: 0` → `"0"`).
  - `pkg/cli/pathguard`: resolved paths never escape the workspace; null-byte,
    overlong, `/proc`/`/sys`/`/dev` output paths rejected.
  - `pkg/accept/verify`: sign/verify round-trip invariant; tamper and wrong-key
    rejection; corrupted batch signatures.
- `go test -race ./...` passes; golangci-lint v2.13.1 reports zero issues.

### Benchmarks
First baselines for `pkg/ingestion` and `pkg/epss` recorded in
`doc/benchmarks/wardex-v2.5.0.md` (e.g. LoadJSON 100 controls:
~365 μs/op; Sign/Verify 100 enrichments: ~100/~86 μs/op). These anchor the §5.1
no-regression criterion (a future migration must not regress > 1%).

### Changed
- Hand-rolled bubble sorts replaced with `slices.SortFunc` (`main.go` roadmap,
  `pkg/sdk/assess.go`, `cmd/chain/seal.go`).
- `config.ApplyProfile` accepts `io.Writer` instead of `*os.File`.
- `.golangci.yml`: enable `gomodguard_v2` (gomodguard deprecated in v2.12.0).
- `.gitignore`: anchors `benchmarks/` to repo root.

### Breaking / Migration Notes
- **Go ≥ 1.27** required to build Wardex.
- `pkg/accept`, `accept.ConfigHash`, `accept.ReadReport` deprecated; import the
  sub-packages or `internal/cpl`/`pkg/report` directly (removed in v3.0).
- RBAC profile warning and gate hints now emitted through `slog` and the
  injected logger.
