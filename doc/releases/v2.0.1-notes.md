# Wardex v2.0.1 Release Notes

**Release Date:** 2026-06-10
**Version:** 2.0.1
**Theme:** Security Hardening

---

## Highlights

### Weak HMAC Fallback Removed
`cmd/evaluate/evaluate.go` now returns an error when `WARDEX_ACCEPT_SECRET` is
unset, instead of falling back to `"REDACTED_WEAK_SECRET_REMOVED"`.

**Impact:** silent weak-signature acceptances are impossible (CRA-critical).

### Path Traversal Hardening
`SafePath` applied in `pkg/trust/seal.go` — path validation before
`os.ReadFile` prevents path traversal via sealed configs (CRA-critical).

### Supply-Chain Pinning
- CLA action pinned to SHA `ca4a40a7d1004f18d9960b404b97e5f30a505a08` instead
  of tag `v2.6.1`.
- Global `-exclude=G304` removed from gosec in CI; inline suppressions added in
  `analyze-gaps.go`, `wexstate.go`, `store.go`, `keyring.go`.

### Linting & Security Gates
- `.golangci.yml` expanded to 9 active linters (staticcheck, gosec, gomodguard,
  misspell, exhaustive, unused, errcheck, govet, ineffassign) with v2 config —
  0 issues.
- New `make security` target (govulncheck + gosec).
- `SECURITY.md` updated with real contact (`andre.ataide@proton.me`) and PGP
  fingerprint `979A C8CE 8F35 7652`.
